Build a playable replica of the game 2048 as a single self-contained `index.html` file in the workspace root (all CSS and JavaScript inline — no external assets or CDN links).

Requirements:

- 4×4 grid with the real 2048 rules: arrow keys (and WASD) slide all tiles in a direction; equal tiles merge once per move into their double; a new tile (2 with ~90% probability, 4 otherwise) spawns on a random empty cell after each move.
- Score tracking (sum of merge results) plus a persistent best score via `localStorage`.
- Win detection (a 2048 tile appears — show a "you win" banner and allow continuing) and game-over detection (no moves left — show a game-over banner with a restart button).
- Tile colors that scale with the value (2→2048+), tile spawn/merge animations, and a clean responsive layout that works at common window sizes.
- No build step, no dependencies: opening `index.html` in a browser must start the game.
